# Glowfin Games website

Static studio site. Read README.md (layout, deploying) and AGENTS.md (rules, how to add a game) first.

- Edit source (`site.json`, `games/<id>/`, `assets/`, `build.py`), run `python3 build.py`, commit source and the rebuilt `docs/` together, push to `main` (Cloudflare Pages serves `docs/` at glowfingames.com). Alex: push straight to main, no PRs.
- Check pages at 390 px and 1440 px wide before pushing and post screenshots to Alex.
